SMART ENTITY TIMER 1.0.0 — FINAL

Smart Entity Timer 1.0.0 includes the backend and Smart Entity Timer Card in one integration package.

HACS — RECOMMENDED
1. Install/update Smart Entity Timer from HACS.
2. If upgrading from 0.3.0 + the standalone Smart Entity Timer Card, stop/cancel all active timers and create a backup first.
3. Update Smart Entity Timer to 1.0.0.
4. BEFORE restarting Home Assistant, remove Smart Entity Timer Card from HACS.
5. Restart Home Assistant.
6. Fully reload the browser or close/reopen the Companion App.
7. Existing cards should render without YAML changes.
8. On a clean 1.0.0 installation, the card is included automatically; do not install the standalone card.

EXPECTED BUNDLED RESOURCE
/smart_entity_timer_static/smart-entity-timer-card.js?v=1.0.0
Type: JavaScript module

MANUAL INSTALLATION
1. Create a Home Assistant backup.
2. Ensure all Smart Entity Timer timers are idle before an upgrade.
3. Copy custom_components/smart_entity_timer to /config/custom_components/smart_entity_timer.
4. Replace existing files.
5. Remove the old standalone Card HACS/resource if present.
6. Restart Home Assistant.
7. Fully reload the frontend.
