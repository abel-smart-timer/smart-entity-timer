SMART ENTITY TIMER 1.0.0 — TEST CANDIDATE

Smart Entity Timer 1.0.0 includes the backend and Smart Entity Timer Card in one integration package.

CLEAN MANUAL TEST
1. Copy custom_components/smart_entity_timer to /config/custom_components/smart_entity_timer.
2. Restart Home Assistant.
3. Add Smart Entity Timer from Settings > Devices & services.
4. Create a timer.
5. Open a dashboard and add Smart Entity Timer Card from the card picker.
6. No separate card resource or HACS card repository should be required.

UPGRADE TEST FROM 0.3.0
1. Stop/cancel every active Smart Entity Timer.
2. Create a Home Assistant backup.
3. Replace the integration with 1.0.0.
4. BEFORE restarting, remove Smart Entity Timer Card from HACS (or remove its old dashboard resource if it was installed manually).
5. Restart Home Assistant.
6. Fully reload the browser/app.
7. Existing cards must render without YAML changes.

HACS TEST BEFORE STABLE RELEASE
After uploading the candidate files to GitHub main, use HACS > Smart Entity Timer > Redownload > Need a different version? > main.
Then remove the standalone Smart Entity Timer Card from HACS before restarting Home Assistant.

DO NOT CREATE v1.0.0 RELEASE UNTIL docs/TEST_PLAN_1.0.0.md IS COMPLETE.
