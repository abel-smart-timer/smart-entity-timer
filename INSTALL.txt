SMART ENTITY TIMER 0.1.0 — MANUAL INSTALLATION

1. Create a Home Assistant backup.
2. Extract the installation ZIP directly into Home Assistant's /config directory.
3. Confirm this file exists:
   /config/custom_components/smart_entity_timer/manifest.json
4. Restart Home Assistant.
5. Go to Settings > Devices & services > Add integration.
6. Search for Smart Entity Timer.

Minimum Home Assistant version: 2026.7.0

This release contains the integration/backend only. The custom dashboard card is the next development stage after functional testing.
