SMART ENTITY TIMER 1.0.1 — DOCUMENTATION / PACKAGING PATCH

Smart Entity Timer 1.0.1 remains one HACS package containing:
- backend integration
- bundled Smart Entity Timer Card

UPGRADE FROM 1.0.0
1. Create a Home Assistant backup.
2. Update Smart Entity Timer to 1.0.1 in HACS.
3. Restart Home Assistant.
4. Fully reload the browser or close/reopen the Companion App.
5. Existing timers and cards should continue working without YAML changes.

UPGRADE FROM 0.3.0 + STANDALONE CARD
1. Wait for all Smart Entity Timer timers to become idle.
2. Create a backup.
3. Update Smart Entity Timer to 1.0.1.
4. BEFORE restarting Home Assistant, remove the standalone Smart Entity Timer Card repository from HACS.
5. Restart Home Assistant.
6. Fully reload the frontend.
7. Existing cards should render without YAML changes.

CLEAN INSTALL
1. Install Smart Entity Timer from HACS.
2. Restart Home Assistant.
3. Add the integration from Settings > Devices & services.
4. Create at least one Timer Config Subentry.
5. Add Smart Entity Timer Card to a dashboard with the visual editor or YAML.
6. Do not install Smart Entity Timer Card separately.

EXPECTED BUNDLED RESOURCE
/smart_entity_timer_static/smart-entity-timer-card.js?v=1.0.1
Type: JavaScript module

MANUAL INSTALLATION
1. Create a Home Assistant backup.
2. Ensure all Smart Entity Timer timers are idle before an upgrade.
3. Copy custom_components/smart_entity_timer to /config/custom_components/smart_entity_timer.
4. Replace existing files.
5. Remove the old standalone Card HACS/resource if still present.
6. Restart Home Assistant.
7. Fully reload the frontend.
